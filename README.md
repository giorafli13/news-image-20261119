## How it works

`main.py` (Python 3.13, standard library only) copies the bundled
`entry.png` to the output directory the grader provides
(`MAKEFUN_OUTPUT_DIR`, or `/output` in the grading container). No network,
fully deterministic: the same input always produces the same output bytes.

## Run it locally

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
# out/entry.png — 1024x1024, under 1 MiB
```
